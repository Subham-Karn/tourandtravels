# 🌍 Tour & Travels Website

A dynamic Tour & Travels web application built using **Node.js, Express.js, EJS, and Bootstrap**. The website allows users to explore travel destinations, browse tour packages, and contact the travel agency through a responsive and user-friendly interface.

---

## 🚀 Features

- Responsive User Interface
- Dynamic EJS Templating
- Home Page
- About Page
- Tour Packages
- Destination Listing
- Tour Details
- Contact Page
- Reusable Layouts (Header & Footer)
- Bootstrap Responsive Design
- Clean Project Structure

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/tour-travels.git
```

### Navigate to Project

```bash
cd tour-travels
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm start
```

or

```bash
node app.js
```

The application will run at:

```
http://localhost:3000
```
